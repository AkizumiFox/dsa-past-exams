\begin{pastsoln}
圖有負權重的邊（B$\to$C 是 $-4$、E$\to$D 是 $-5$、D$\to$A 是 $-1$），不能用 Dijkstra；用 Floyd--Warshall
（資結書第~25.6~節）。 先檢查負環：經過 D$\to$A 的環有 A$\to$B$\to$D$\to$A（$5 + 2 - 1 = 6$）和
A$\to$B$\to$E$\to$D$\to$A（$5 + 3 - 5 - 1 = 2$），都是正的，其他頂點（C、F、G）出去後回不到 A、B、D、E，
所以沒有負環，最短距離都有定義。 最後矩陣的對角線都是 $0$，也印證沒有負環。

$D^{(k)}[i][j]$ 表示「中間只經過前 $k$ 個頂點（依 A, B, \ldots, G 的順序）」時 $i$ 到 $j$ 的最短距離，
\[
D^{(k)}[i][j] = \min\bigl(D^{(k-1)}[i][j],\ D^{(k-1)}[i][k] + D^{(k-1)}[k][j]\bigr).
\]
$D^{(0)}$ 是邊的權重（沒有邊是 $\infty$），每一步粗體是這一輪變小的格子；列是起點、行是終點。

各輪的更新：
\begin{itemize}
\item $k = $ A：只有 D 進得來（D$\to$A $= -1$）。 D$\to$B $= -1 + 5 = 4$，D$\to$C $= -1 + 2 = 1$。
\item $k = $ B：A$\to$C $= 5 - 4 = 1 < 2$；A$\to$D $= 5 + 2 = 7$；A$\to$E $= 5 + 3 = 8$；D$\to$C
$= 4 - 4 = 0$；D$\to$E $= 4 + 3 = 7$。
\item $k = $ C：A$\to$F $= 1 + 2 = 3$；B$\to$F $= -4 + 2 = -2$；D$\to$F $= 0 + 2 = 2$。
\item $k = $ D：A$\to$G $= 7 + 1 = 8$；B$\to$A $= 2 - 1 = 1$；B$\to$G $= 2 + 1 = 3$；E$\to$A $= -5 - 1
= -6$；E$\to$B $= -5 + 4 = -1$；E$\to$C $= -5 + 0 = -5$；E$\to$F $= -5 + 2 = -3 < 4$；E$\to$G
$= -5 + 1 = -4 < 3$。
\item $k = $ E：A$\to$D $= 8 - 5 = 3 < 7$；A$\to$G $= 8 - 4 = 4 < 8$；B$\to$A $= 3 - 6 = -3 < 1$；B$\to$D
$= 3 - 5 = -2 < 2$；B$\to$G $= 3 - 4 = -1 < 3$。
\item $k = $ F：C$\to$G $= 2 + 3 = 5$。
\item $k = $ G：G 沒有出邊，沒有變化。
\end{itemize}
$D^{(7)}$ 就是所有點對的最短距離。 例如 B 到 A 是 $-3$，路徑 B$\to$E$\to$D$\to$A（$3 - 5 - 1$）；E 到 G
是 $-4$，路徑 E$\to$D$\to$G；A 到 G 是 $4$，路徑 A$\to$B$\to$E$\to$D$\to$G（$5 + 3 - 5 + 1$）。 C、F、G
三列的 $\infty$ 表示從它們出發到不了那些頂點。 時間 $\Theta(n^3)$。
