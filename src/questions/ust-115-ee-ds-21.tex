\begin{pastexam}[label={px:ust-115-ee-ds-21}]{臺聯大電機類 115 學年度 第 21 題}
（單選；2 分）

\textbf{Suppose that we have a Binary Search Tree (BST) consisting of nodes, where each node stores a
unique integer between 1 and 1000. Which of the following sequences could be a VALID sequence of
nodes examined when searching for the number 101?}
\begin{enumerate}[label=(\Alph*)]
\item 80, 252, 90, 130, 110, 100, 120, 101
\item 252, 130, 120, 110, 100, 90, 80, 101
\item 80, 90, 252, 110, 130, 120, 100, 101
\item 80, 252, 90, 100, 130, 120, 110, 101
\item 252, 130, 110, 80, 90, 100, 120, 101
\end{enumerate}
\end{pastexam}

\begin{pastsoln}
答案是 (D)。

搜尋 $101$ 時（資結書虛擬碼~9.1），每經過一個節點 $v$：$101 < v$ 就往左，之後看到的節點都必須
$< v$；$101 > v$ 就往右，之後看到的都必須 $> v$。 所以維護一個區間 $(\mathit{lo}, \mathit{hi})$，
每個節點都要落在目前的區間裡，再用它把區間縮小。 一開始區間是 $(0, 1001)$。

\begin{itemize}
\item (A) $80$：往右，$(80, 1001)$；$252$：往左，$(80, 252)$；$90$：往右，$(90, 252)$；$130$：往左，
$(90, 130)$；$110$：往左，$(90, 110)$；$100$：往右，$(100, 110)$；$120$ 不在 $(100, 110)$ 裡。
不合法。
\item (B) $252$、$130$、$120$、$110$ 都往左，區間變成 $(0, 110)$；$100$：往右，$(100, 110)$；$90$
不在區間裡。 不合法。
\item (C) $80$：$(80, 1001)$；$90$：$(90, 1001)$；$252$：$(90, 252)$；$110$：往左，$(90, 110)$；
$130$ 不在區間裡。 不合法。
\item (D) $80$：$(80, 1001)$；$252$：$(80, 252)$；$90$：$(90, 252)$；$100$：往右，$(100, 252)$；
$130$：往左，$(100, 130)$；$120$：$(100, 120)$；$110$：$(100, 110)$；$101$ 在區間裡，找到。 合法。
\item (E) $252$、$130$、$110$ 都往左，區間 $(0, 110)$；$80$、$90$、$100$ 都往右，區間變成
$(100, 110)$；$120$ 不在區間裡。 不合法。
\end{itemize}
只有 (D) 每一步都落在區間裡。
\end{pastsoln}
