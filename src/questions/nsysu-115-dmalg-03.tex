\begin{pastexam}[label={px:nsysu-115-dmalg-03}]{中山資工所資安組 115 學年度 第 4 題}
（計算）

(10\%) Find the generating function for the sequence 1, 2, 4, 7, 11, \ldots.
\end{pastexam}

\begin{pastsoln}
答案：$A(x) = \dfrac{1 - x + x^2}{(1 - x)^3}$。

\textbf{找規律}。 只給了前五項，要先決定一般項。 相鄰兩項的差是 $1, 2, 3, 4$，最自然的讀法是差一直加一：
$a_0 = 1$，$a_n = a_{n-1} + n$（$n \ge 1$）。 於是
\[
a_n = 1 + (1 + 2 + \cdots + n) = 1 + \frac{n(n+1)}{2},
\]
$n = 0, 1, 2, 3, 4$ 代入得 $1, 2, 4, 7, 11$，和題目相符。

\textbf{用遞迴式求生成函數}（資結書第~2.6~節的做法）。 令 $A(x) = \sum_{n \ge 0} a_n x^n$。 把 $a_n - a_{n-1} = n$
乘上 $x^n$ 對 $n \ge 1$ 加總：
\[
\sum_{n \ge 1} (a_n - a_{n-1}) x^n = \bigl(A(x) - a_0\bigr) - x A(x) = (1 - x) A(x) - 1,
\qquad
\sum_{n \ge 1} n x^n = \frac{x}{(1 - x)^2}.
\]
最後一個等式是把 $\frac{1}{1 - x} = \sum_{n \ge 0} x^n$ 兩邊微分再乘 $x$。 所以
\[
(1 - x) A(x) = 1 + \frac{x}{(1 - x)^2}
\quad\Longrightarrow\quad
A(x) = \frac{1}{1 - x} + \frac{x}{(1 - x)^3} = \frac{(1 - x)^2 + x}{(1 - x)^3} = \frac{1 - x + x^2}{(1 - x)^3}.
\]

\textbf{檢查}。 用 $\frac{1}{(1 - x)^3} = \sum_{n \ge 0} \binom{n + 2}{2} x^n$，係數依序是 $1, 3, 6, 10, 15, \ldots$。
$A(x) = (1 - x + x^2) \sum \binom{n+2}{2} x^n$ 的前幾個係數：
\[
\begin{aligned}
x^0 &: 1, & x^1 &: 3 - 1 = 2, & x^2 &: 6 - 3 + 1 = 4,\\
x^3 &: 10 - 6 + 3 = 7, & x^4 &: 15 - 10 + 6 = 11, & x^5 &: 21 - 15 + 10 = 16,
\end{aligned}
\]
和 $1 + n(n+1)/2$ 一致（下一項是 $16$）。
\end{pastsoln}
