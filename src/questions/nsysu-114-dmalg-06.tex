\begin{pastexam}[label={px:nsysu-114-dmalg-06}]{中山資工所資安組 114 學年度 第 7 題}
（計算）

{[10\%]} Solve the following recurrence relation.
$a_{n+2} - 5a_{n+1} + 6a_n = 5^n, n \ge 0, a_0 = 0, a_1 = 1$.
\end{pastexam}

\begin{pastsoln}
答案：$a_n = \dfrac{1}{2}\cdot 3^n - \dfrac{2}{3}\cdot 2^n + \dfrac{1}{6}\cdot 5^n$，$n \ge 0$。

這是常係數線性非齊次遞迴式（資結書第~2.5~節）：解 = 齊次解 + 一個特解，再用初始條件定係數。

\textbf{齊次解}。 特徵方程式 $r^2 - 5r + 6 = 0$，$(r - 2)(r - 3) = 0$，根 $r = 2, 3$。 齊次解
$a_n^{(h)} = c_1 2^n + c_2 3^n$。

\textbf{特解}。 右邊是 $5^n$，$5$ 不是特徵根，猜 $a_n^{(p)} = A \cdot 5^n$。 代入：
\[
A \cdot 5^{n+2} - 5A \cdot 5^{n+1} + 6A \cdot 5^n = A \cdot 5^n (25 - 25 + 6) = 6A \cdot 5^n = 5^n,
\]
得 $A = \frac{1}{6}$。

\textbf{定係數}。 $a_n = c_1 2^n + c_2 3^n + \frac{1}{6} 5^n$。
\begin{align*}
a_0 = 0 &:\quad c_1 + c_2 + \tfrac{1}{6} = 0, \\
a_1 = 1 &:\quad 2c_1 + 3c_2 + \tfrac{5}{6} = 1 .
\end{align*}
第一式得 $c_1 = -\frac{1}{6} - c_2$，代入第二式：$-\frac{1}{3} - 2c_2 + 3c_2 = \frac{1}{6}$，
$c_2 = \frac{1}{2}$，$c_1 = -\frac{2}{3}$。 所以
\[
a_n = -\frac{2}{3}\cdot 2^n + \frac{1}{2}\cdot 3^n + \frac{1}{6}\cdot 5^n
= \frac{3^{n+1} - 2^{n+2} + 5^n}{6} .
\]

\textbf{核對}：由遞迴式直接算 $a_2 = 5a_1 - 6a_0 + 5^0 = 6$，$a_3 = 5 \cdot 6 - 6 \cdot 1 + 5 = 29$，
$a_4 = 5 \cdot 29 - 6 \cdot 6 + 25 = 134$。 公式：$a_2 = (27 - 16 + 25)/6 = 6$，
$a_3 = (81 - 32 + 125)/6 = 29$，$a_4 = (243 - 64 + 625)/6 = 134$，都相符；$n = 0, 1$ 也分別是
$(3 - 4 + 1)/6 = 0$、$(9 - 8 + 5)/6 = 1$。
\end{pastsoln}
