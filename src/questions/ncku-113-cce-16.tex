（簡答）

(5 pts) For any nonempty binary tree, $T$, if $n_0$ is the number of leaf nodes and $n_2$ is the
number of nodes of degree 2. Pleases show the relation between $n_0$ and $n_2$.
\end{pastexam}

\begin{pastsoln}
關係是 $n_0 = n_2 + 1$（資結書定理~7.2）。

\textbf{證明。} 令 $n_1$ 是分支度為 $1$ 的節點數，$n$ 是總節點數。 二元樹每個節點的分支度只能是
$0$、$1$、$2$，所以
\[
n = n_0 + n_1 + n_2 . \tag{1}
\]
再數邊。 除了根，每個節點恰好有一條邊連到它的父節點，所以邊數是 $n - 1$。 另一方面，每條邊
都是從某個父節點連出去的，分支度 $1$ 的節點連出 $1$ 條、分支度 $2$ 的連出 $2$ 條，所以邊數也
等於 $n_1 + 2n_2$：
\[
n - 1 = n_1 + 2n_2 . \tag{2}
\]
把 (1) 代入 (2)：$n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$，消去 $n_1$ 得 $n_0 = n_2 + 1$。\hfill$\blacksquare$

例如只有一個根時 $n_0 = 1$、$n_2 = 0$；三個節點的完滿二元樹 $n_0 = 2$、$n_2 = 1$，都符合。
題目要求樹非空，是因為空樹 $n_0 = n_2 = 0$，式子不成立。
\end{pastsoln}
