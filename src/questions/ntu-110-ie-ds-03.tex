\begin{pastexam}[label={px:ntu-110-ie-ds-03}]{臺大工工所 110 學年度 第 3 題}
（單選；每題 3 分，答錯不倒扣）

In this exam, the height of a leaf (in either a tree or heap) is defined as 0; the size of a tree/heap is
defined as the total number of keys (items) it stores.

For a 2-3-4 tree of height 5, let x be the minimum possible size, y be the maximum possible size, then
(xy) mod 5 is

(A)~0 \qquad (B)~1 \qquad (C)~2 \qquad (D)~3 \qquad (E)~4
\end{pastexam}

\begin{pastsoln}
答案是 (A)。 $x = 63$、$y = 4095$，$xy = 257985$，除以 $5$ 餘 $0$。

2-3-4 樹所有葉節點在同一層（資結書第~11.1.5~節）。 高度 $5$（葉節點高度 $0$）表示從根到葉一共
$6$ 層，第 $i$ 層（$i = 0..5$）的節點數由上一層的分支數決定。 size 是鍵的個數。

\textbf{最少}：每個節點都是 2-節點（$1$ 個鍵、$2$ 個子節點），第 $i$ 層有 $2^i$ 個節點，
\[
  x = \sum_{i=0}^{5} 2^i = 2^6 - 1 = 63 .
\]
\textbf{最多}：每個節點都是 4-節點（$3$ 個鍵、$4$ 個子節點），第 $i$ 層有 $4^i$ 個節點，
\[
  y = 3 \sum_{i=0}^{5} 4^i = 3 \cdot \frac{4^6 - 1}{3} = 4^6 - 1 = 4095 .
\]
這兩個數也可以從資結書第~11.1.5~節的 $\log_4(n + 1) \le h' \le \lg(n + 1)$ 反推（$h' = 6$ 是層數）。

$xy = 63 \times 4095 = 257985$，個位數是 $5$，所以 $xy \bmod 5 = 0$，選 (A)。 （其實 $4095$ 的個位數是 $5$，
不必乘開就知道。） 如果把高度 $5$ 誤當成 $5$ 層，會得到 $x = 31$、$y = 1023$，$xy = 31713$，餘 $3$，
會選錯成 (D)。
\end{pastsoln}
