\begin{pastexam}[label={px:ncku-111-ee-ds-06}]{成大電機所 111 學年度 單選題第 6 題}
（單選；每題 4 分）

Which of the following data structure is a non-linear data structure?

A.~Arrays \qquad B.~Linked lists \qquad C.~Trees \qquad D.~None of above
\end{pastexam}

\begin{pastsoln}
答案是 C。

\begin{itemize}
\item A.~陣列、B.~串列：元素排成一列，是線性的。 錯。
\item C.~樹：一個節點可以有好幾個子節點，資料之間是階層關係，不是排成一列，是非線性的（資結書第~7.1~節）。 對。
\item D.~都不是：C 就是。 錯。
\end{itemize}
\end{pastsoln}
