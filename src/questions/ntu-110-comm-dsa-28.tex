（單選；每題 2 分，答錯不倒扣）

In this exam,
\begin{itemize}
\item The height of a leaf (in either a tree or heap) is defined as 0.
\item The depth of the root (in either a tree or heap) is defined as 0.
\item The degree of a node (in either a tree or heap) is defined as the number of its children.
\item The size of a tree/heap is defined as the total number of keys (items) it stores.
\item All heaps, unless otherwise specified, are min heaps.
\end{itemize}

For a 2-3-4 tree of height 5, let x be the minimum possible size, y be the maximum possible size, then (xy) mod 5 is

A.~0 \qquad B.~1 \qquad C.~2 \qquad D.~3 \qquad E.~4
\end{pastexam}

\begin{pastsoln}
答案是 A（0）。

2-3-4 樹所有葉子在同一層（資結書第~10.4~節、第~11.1.5~節）。 葉子高度為 $0$，高度 $5$ 表示從根到葉子
有 $5$ 條邊，共 $6$ 層節點（深度 $0..5$）。 「size」是鍵的個數。
\begin{itemize}
\item \textbf{最少}：每個節點都是 2-節點（$1$ 個鍵、$2$ 個子節點），是一棵滿二元樹，節點數
$1 + 2 + \cdots + 2^5 = 2^6 - 1 = 63$，每個 $1$ 個鍵，$x = 63$。
\item \textbf{最多}：每個節點都是 4-節點（$3$ 個鍵、$4$ 個子節點），節點數
$1 + 4 + \cdots + 4^5 = \tfrac{4^6 - 1}{3} = 1365$，鍵數 $3 \times 1365 = 4^6 - 1 = 4095$，$y = 4095$。
\end{itemize}
$xy = 63 \times 4095 = 257985$。 $4095$ 是 $5$ 的倍數，所以 $xy \bmod 5 = 0$，選 A。
\end{pastsoln}
