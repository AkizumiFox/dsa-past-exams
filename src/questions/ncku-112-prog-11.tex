\begin{pastexam}[label={px:ncku-112-prog-11}]{成大資訊聯招 112 學年度 第 11 題}
（問答）

(10\%) Use the master method to give tight asymptotic bounds for the following recursive
$T(n)=27T(n/3)+\Theta(n^3/\lg n)$. (Assume that $T(n)$ is a constant for sufficiently small $n$.)
\end{pastexam}

\begin{pastsoln}
答案：$T(n) = \Theta(n^3 \lg\lg n)$。 標準的主定理三種情形都不適用，要另外算。

\textbf{主定理不適用}（資結書定理~2.4）。 $a = 27$、$b = 3$，$n^{\log_b a} = n^{\log_3 27} = n^3$。
$f(n) = \Theta(n^3/\lg n)$ 比 $n^3$ 小，但不是\textbf{多項式地}小：要用第一種情形需要 $f(n) = O(n^{3 - \epsilon})$，
可是對任何 $\epsilon > 0$，$\dfrac{n^3/\lg n}{n^{3-\epsilon}} = \dfrac{n^\epsilon}{\lg n} \to \infty$，做不到。 第二種
情形要 $f(n) = \Theta(n^3)$（或資結書定理~2.5 的 $\Theta(n^3 \lg^k n)$，$k \ge 0$），$k = -1$ 不在範圍裡；第三種
情形要 $f$ 比 $n^3$ 大，也不是。 $f$ 落在第一、二種情形中間的空隙。

\textbf{用遞迴樹算}（資結書第~2.3~節）。 設 $n = 3^m$，$f(n) = c\,n^3/\lg n$。 第 $i$ 層（$i = 0, 1, \ldots, m - 1$）
有 $27^i$ 個大小 $n/3^i$ 的子問題，這一層的成本
\[
27^i \cdot \frac{c\,(n/3^i)^3}{\lg(n/3^i)} = \frac{c\,n^3}{\lg n - i \lg 3} = \frac{c\,n^3}{(m - i)\lg 3}.
\]
（$27^i/(3^i)^3 = 1$；$\lg n = m \lg 3$。） 最下層有 $27^m = n^3$ 個常數大小的子問題，成本 $\Theta(n^3)$。 加起來，
令 $k = m - i$ 從 $1$ 跑到 $m$：
\[
T(n) = \frac{c\,n^3}{\lg 3}\sum_{k=1}^{m}\frac{1}{k} + \Theta(n^3) = \frac{c\,n^3}{\lg 3} H_m + \Theta(n^3).
\]
調和數 $H_m = \ln m + O(1) = \Theta(\lg m)$，而 $m = \log_3 n$，$\lg m = \lg\lg n - \lg\lg 3 = \Theta(\lg\lg n)$。 所以
\[
T(n) = \Theta(n^3 \lg\lg n).
\]
上下界都成立，因為每一層的成本是 $\Theta$ 等級的（$f$ 給的是 $\Theta$），整個和是 $\Theta$。 （這是推廣的主定理
中「$f(n) = \Theta(n^{\log_b a}/\lg n)$ 時 $T(n) = \Theta(n^{\log_b a}\lg\lg n)$」的情形；照題目要求用 master method
的話，答題時要先寫出標準的三種情形為什麼都不適用。）
\end{pastsoln}
