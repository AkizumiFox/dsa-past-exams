\begin{pastexam}[label={px:nchu-114-dsa-10}]{中興資工所甲組 114 學年度 單選題第 10 題}
（單選；每題 3 分，未答題得 0 分，答錯不倒扣）

Which of the following statements about topological sorting in a directed acyclic graph (DAG) is true?

(A)~A DAG can have multiple valid topological orders.\\
(B)~A strongly connected graph always has at least one topological order.\\
(C)~Topological sorting guarantees a unique order in any DAG.\\
(D)~A directed graph with a cycle can still have a valid topological order.
\end{pastexam}

\begin{pastsoln}
答案是 (A)。

\begin{itemize}
\item (A) 對。 例如兩個頂點 $a$、$b$、沒有邊，$a, b$ 和 $b, a$ 都是拓樸順序；三個頂點 $a \to b$、
$a \to c$ 也有 $a, b, c$ 和 $a, c, b$ 兩種。 拓樸順序唯一，若且唯若順序中每兩個相鄰頂點之間都有邊，也就是
有一條經過所有頂點的路徑（資結書定理~22.5）。
\item (B) 錯。 有兩個以上頂點的強連通圖裡，任兩點 $u$、$v$ 互相可達，$u \leadsto v \leadsto u$ 形成環，
有環的圖沒有拓樸順序。 （只有一個頂點的圖才是例外，「always」不成立。）
\item (C) 錯。 見 (A) 的例子。
\item (D) 錯。 環上的頂點 $v_1 \to v_2 \to \cdots \to v_k \to v_1$ 要求 $v_1$ 排在 $v_2$ 前面、……、
$v_k$ 排在 $v_1$ 前面，矛盾。 有向圖有拓樸順序若且唯若它沒有環（資結書定理~22.2）。
\end{itemize}
\end{pastsoln}
