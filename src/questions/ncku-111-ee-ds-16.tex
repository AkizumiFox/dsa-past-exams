\begin{pastexam}[label={px:ncku-111-ee-ds-16}]{成大電機所 111 學年度 單選題第 16 題}
（單選；每題 4 分）

The operation of processing each element in the list is known as

A.~Sorting \qquad B.~Merging \qquad C.~Inserting \qquad D.~Traversal
\end{pastexam}

\begin{pastsoln}
答案是 D。

把串列裡的每個元素都拜訪（處理）一次，叫\textbf{走訪}（traversal），例如從第一個節點沿著 \texttt{next} 走到 \texttt{NULL}，
把每個節點的值印出來或加總（資結書第~5.1~節）。
\begin{itemize}
\item A.~排序：把元素排成某種順序。 錯。
\item B.~合併：把兩個串列合成一個。 錯。
\item C.~插入：加入一個新元素。 錯。
\item D.~走訪：對。
\end{itemize}
\end{pastsoln}
