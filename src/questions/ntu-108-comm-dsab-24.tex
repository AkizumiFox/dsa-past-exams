\begin{pastexam}[label={px:ntu-108-comm-dsab-24}]{臺大電信所 108 學年度（B）第 24 題}
（單選；每題 2.5 分，答錯不倒扣）

Also note that in this exam, the degree of a node $x$ in a tree indicates the number of children
of $x$.

The number of items in a binomial tree whose root has degree 8 is

A.~9 \qquad B.~34 \qquad C.~64 \qquad D.~128 \qquad E.~256
\end{pastexam}

\begin{pastsoln}
答案是 E。

根的階數（子節點數）是 $k$ 的二項樹就是 $B_k$（資結書第~8.5~節）。 $B_k$ 由兩棵 $B_{k-1}$ 組成，節點數
$|B_k| = 2|B_{k-1}|$、$|B_0| = 1$，所以 $|B_k| = 2^k$。 $k = 8$ 時是 $2^8 = 256$。 A 的 $9$ 是
$k + 1$（只算根和它的子節點）；B 的 $34$ 是費氏堆積裡階數 $8$ 的節點子樹的最小節點數 $F_{10}$，不是
二項樹；C、D 是 $B_6$、$B_7$。
\end{pastsoln}
