\begin{pastsoln}
答案是 c)。

最大堆積的刪除就是刪掉根（最大值，資結書第~8.1~節）：把最後一個元素搬到根，堆積大小減 $1$，再從根
往下調整，每次和比較大的子節點比，比它小就交換。 陣列從 $1$ 開始，$i$ 的子節點是 $2i$、$2i + 1$。
\begin{enumerate}
\item 拿掉 $A[1] = 75$，最後一個 $A[7] = 29$ 搬到根：$\langle 29, 58, 67, 42, 55, 30 \rangle$。
\item $A[1] = 29$ 的子節點 $58$、$67$，較大的是 $67$，$29 < 67$，交換：
$\langle 67, 58, 29, 42, 55, 30 \rangle$。
\item $A[3] = 29$ 的子節點只有 $A[6] = 30$，$29 < 30$，交換：$\langle 67, 58, 30, 42, 55, 29 \rangle$。
\item $A[6]$ 沒有子節點，停。
\end{enumerate}
結果 $[1..6] = 67, 58, 30, 42, 55, 29$，$[7]$ 空出來，就是 c)。

其他選項：a) 把 $42$、$55$ 對調了，$A[2] = 58$ 的子樹在刪除時根本沒動到；b) 是把剩下的數排好序，
不是堆積刪除的結果；d) 停在第 2 步，$A[3] = 29$ 比子節點 $30$ 小，違反最大堆積。
\end{pastsoln}
