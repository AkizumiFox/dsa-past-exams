\begin{pastexam}[label={px:ust-114-ee-ds-11}]{臺聯大電機類 114 學年度 第 11 題}
（單選；2 分，答錯不倒扣）

Suppose that we have numbers between 1 and 1000 in a binary search tree and we want to search the
number 101. Which of the following sequences could possibly be the sequence of nodes examined?

(A)~20, 252, 41,49, 130, 120, 131, 101\\
(B)~252, 42, 79, 200, 190, 86, 130, 121, 101\\
(C)~80, 252, 90, 130, 120, 125, 110, 101\\
(D)~90, 252, 100, 131, 130, 92, 110, 101
\end{pastexam}

\begin{pastsoln}
答案是 (B)。

搜尋 $101$ 時，每經過一個節點 $x$：$101 < x$ 就往左，之後所有節點都 $< x$；$101 > x$ 就往右，之後
都 $> x$。 所以沿路維持一個區間 $(\mathit{lo}, \mathit{hi})$，下一個節點必須落在區間裡（資結書
第~9.1~節）。 起始區間 $(0, 1001)$。
\begin{itemize}
\item (A)：20 往右 $(20, 1001)$；252 往左 $(20, 252)$；41 往右 $(41, 252)$；49 往右 $(49, 252)$；
130 往左 $(49, 130)$；120 往左 $(49, 120)$；下一個 $131 > 120$，不在區間裡。 不可能。
\item (B)：252 往左 $(0, 252)$；42 往右 $(42, 252)$；79 往右 $(79, 252)$；200 往左 $(79, 200)$；
190 往左 $(79, 190)$；86 往右 $(86, 190)$；130 往左 $(86, 130)$；121 往左 $(86, 121)$；
$101 \in (86, 121)$，找到。 每一步都合法，可能。
\item (C)：80 往右 $(80, 1001)$；252 往左 $(80, 252)$；90 往右 $(90, 252)$；130 往左
$(90, 130)$；120 往左 $(90, 120)$；下一個 $125 > 120$，不可能。
\item (D)：90 往右 $(90, 1001)$；252 往左 $(90, 252)$；100 往右 $(100, 252)$；131 往左
$(100, 131)$；130 往左 $(100, 130)$；下一個 $92 < 100$，不可能。
\end{itemize}
\end{pastsoln}
