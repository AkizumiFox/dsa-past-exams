\begin{pastexam}[label={px:ntut-114-ee-ds-03}]{北科大電機所（戊組） 114 學年度 第 I-3 題}
（單選；4 分）

Breadth-First Search (BFS) and Depth-First Search (DFS) algorithms are based on \textbf{(4\%)}
\begin{enumerate}[label=\alph*)]
\item Sorting techniques
\item Graph traversal strategies
\item Array manipulation
\item Hash calculations
\end{enumerate}
\end{pastexam}

\begin{pastsoln}
答案是 b) Graph traversal strategies。

BFS 和 DFS 都是走訪圖（或樹）的方法：從一個起點出發，有系統地拜訪所有走得到的頂點。 BFS 用佇列，
一層一層往外走；DFS 用堆疊（或遞迴），先一路走到底再回頭（資結書第~21.3、21.4~節）。 它們不是
排序、陣列操作或雜湊的技巧。
\end{pastsoln}
