Answer questions 17-20 according to the following C++-style pseudo-code.
\begin{minted}[fontsize=\small]{cpp}
int funcB(string s) {
    stack<int> st;
    st.push(-1);
    int maxLen = 0;
    for (int i = 0; i < s.length(); i++) {
        if (s[i] == '(') {
            st.push(i);
        } else {
            st.pop();
            if (st.empty()) {
                st.push(i);
            } else {
                maxLen = max(maxLen, i - st.top());
            }
        }
    }
    return maxLen;
}
\end{minted}

Let s = ``()(())'', funcB(s) will return

(A)~0 \qquad (B)~2 \qquad (C)~4 \qquad (D)~6
\end{pastexam}

\begin{pastsoln}
答案是 (D)。

\begin{center}
\small
\begin{tabular}{ccll}
\toprule
$i$ & $s[i]$ & 動作 & 堆疊（底 $\to$ 頂）、maxLen \\
\midrule
 & & 初始 & $[-1]$，0 \\
0 & ( & push 0 & $[-1, 0]$，0 \\
1 & ) & pop；頂端 $-1$，$1 - (-1) = 2$ & $[-1]$，2 \\
2 & ( & push 2 & $[-1, 2]$，2 \\
3 & ( & push 3 & $[-1, 2, 3]$，2 \\
4 & ) & pop；頂端 $2$，$4 - 2 = 2$ & $[-1, 2]$，2 \\
5 & ) & pop；頂端 $-1$，$5 - (-1) = 6$ & $[-1]$，6 \\
\bottomrule
\end{tabular}
\end{center}
回傳 $6$：整個字串 ``()(())'' 都是合法的括號序列。 注意 $i = 1$ 時算出的 $2$ 只是前一段 ``()''，
到 $i = 5$ 時底下的 $-1$ 沒被彈掉，長度是從 $-1$ 之後一路算到 $5$，兩段接起來。 (A)(B)(C) 都不對。
\end{pastsoln}
