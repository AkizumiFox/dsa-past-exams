\begin{pastexam}[label={px:ntu-110-comm-dsa-14}]{臺大電信所 110 學年度（B）第 14 題}
（單選；每題 2 分，答錯不倒扣）

Please choose the best possible answer in each of the following questions. In questions that ask for time complexities, please choose the tightest bound.

Consider an array of size $n$ with perfectly \textit{inversely} sorted order. Which of the following is correct about the running times to sort this array (deterministically)?
\begin{enumerate}[label=\Alph*.]
\item Quicksort: $O(n\lg n)$; Merge Sort: $O(n\lg n)$; Insertion Sort: $O(n^2)$
\item Quicksort: $O(n^2)$; Merge Sort: $O(n^2)$; Insertion Sort: $O(n^2)$
\item Quicksort: $O(n^2)$; Merge Sort: $O(n\lg n)$; Insertion Sort: $O(n\lg n)$
\item Quicksort: $O(n^2)$; Merge Sort: $O(n\lg n)$; Insertion Sort: $O(n^2)$
\end{enumerate}
\end{pastexam}

\begin{pastsoln}
答案是 D。

「deterministically」指快速排序用固定規則選基準（例如取第一個或最後一個），不用亂數。 輸入是由大到小
排好的陣列。
\begin{itemize}
\item \textbf{快速排序}：取最後一個當基準時，基準是整段的最小值，每次都切成 $0$ 和 $m - 1$ 個；
取第一個時基準是最大值，同樣切得最偏。 遞迴式 $T(n) = T(n - 1) + \Theta(n)$，$T(n) = \Theta(n^2)$
（資結書第~14.5~節）。
\item \textbf{合併排序}：不論輸入長什麼樣子，都是對半切、合併 $\Theta(n)$，$T(n) = 2T(n/2) + \Theta(n)
= \Theta(n\lg n)$（資結書第~14.4~節）。
\item \textbf{插入排序}：反序是它的最壞情況，第 $j$ 個元素要和前面 $j - 1$ 個全部比過、全部往後挪，
總比較次數 $1 + 2 + \cdots + (n - 1) = n(n - 1)/2 = \Theta(n^2)$（資結書第~1.3~節）。
\end{itemize}
所以是快速排序 $O(n^2)$、合併排序 $O(n\lg n)$、插入排序 $O(n^2)$，選 D。

逐項：A 的快速排序 $O(n\lg n)$ 錯（要選基準為中位數之類的方法才行，不是一般的固定選法）；B 的合併排序
$O(n^2)$ 雖然是對的上界但不是最緊的，題目要求選最緊的界；C 的插入排序 $O(n\lg n)$ 錯。
\end{pastsoln}
