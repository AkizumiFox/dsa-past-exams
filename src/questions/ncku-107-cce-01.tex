2. Which of the following statement(s) is (are) true?
\begin{enumerate}[label=(\Alph*)]
\item The number of nodes with two children in a binary tree must be smaller than or equal to number of
leaf nodes.
\item The worse time complexity to insert a node into a binary search tree is O(log $n$) when the tree
contains $n$ nodes.
\item There exists $n$+1 thread in a threaded binary search tree with $n$ nodes.
\item If we use a list representation to represent a $k$-ary tree (i.e., at tree of degree k) for $n$
nodes, where each node in a list has a fixed size $k$ to record its children, then $n$($k$-1) + 1
fields will be wasted in the representation.
\end{enumerate}
\end{pastexam}

答案：(A)(C)(D)。
\end{pastsoln}
