\begin{pastexam}[label={px:gk3-113-ds-02}]{高考三級資訊處理 113 年 第二題}
（申論；25 分）

\begin{itemize}[leftmargin=2.2em]
\item[㈠] 快速排序法（Quick Sort）最壞的情況下所需的時間複雜度（Time Complexity）為 O(n$^2$)，請說明是
在何種情況下造成？（10 分）
\item[㈡] 請列出其最壞的時間複雜度為 O(n$^2$)的推導過程。（15 分）
\end{itemize}
\end{pastexam}

\begin{pastsoln}
答案：㈠ 每次分割都切得最不平均（基準是這一段的最小值或最大值，一邊 $0$ 個、另一邊 $m - 1$ 個），例如
固定取第一個或最後一個當基準、而輸入已經排好（遞增或遞減）。 ㈡ $T(n) = T(n-1) + cn$，展開得
$cn(n+1)/2 = O(n^2)$。

下面以資結書虛擬碼~14.8、14.9（Lomuto 分割，取最後一個 $A[r]$ 當基準）為準；Hoare 分割或取第一個當
基準，結論一樣（資結書第~14.5~節）。

\textbf{㈠ 最壞情況。} 快速排序一次分割的成本和這段的長度 $m$ 成正比（基準和其餘 $m - 1$ 個數各比一次），
接著遞迴排兩邊。 如果基準剛好是這一段的最小值或最大值，分割完一邊是空的、另一邊有 $m - 1$ 個，問題
只縮小了一個數，遞迴就要做 $n$ 層。 常見的成因：
\begin{itemize}
\item 固定取最後一個（或第一個）當基準，而輸入\textbf{已經由小到大排好}：每次的基準都是最大值（或最小值）。
\item 同樣的取法，輸入\textbf{由大到小排好}：基準每次都是最小值（或最大值）。
\item 所有數都\textbf{相等}，用 Lomuto 分割（條件 $A[j] \le x$ 全部成立），每次切成 $m - 1$ 和 $0$。
\end{itemize}
例如 $\langle 1, 2, 3, 4, 5\rangle$ 取最後一個當基準：$5$ 比 $4$ 次，切成 $\langle 1, 2, 3, 4\rangle$ 和空；
$4$ 比 $3$ 次……共 $4 + 3 + 2 + 1 = 10$ 次比較，正好是 $\binom{5}{2}$，和逐對比較一樣多。 改用隨機選基準
或三數取中，可以讓這種情況幾乎不會發生，期望時間是 $O(n \lg n)$（資結書定理~14.3）。

\textbf{㈡ 推導。} 設排 $n$ 個數的時間是 $T(n)$，分割花 $cn$（$c$ 是常數），基準把資料切成 $q$ 和
$n - 1 - q$ 個：
\[
T(n) = T(q) + T(n - 1 - q) + cn, \qquad T(0) = T(1) = c'.
\]
最壞情況每次 $q = 0$（或 $q = n - 1$）：
\[
T(n) = T(n - 1) + T(0) + cn = T(n - 1) + cn + c'.
\]
反覆代入：
\begin{align*}
T(n) &= T(n-1) + cn + c' \\
     &= T(n-2) + c(n-1) + cn + 2c' \\
     &\ \ \vdots \\
     &= T(1) + c(2 + 3 + \cdots + n) + (n-1)c' \\
     &= c' + c\left(\frac{n(n+1)}{2} - 1\right) + (n - 1)c' = O(n^2).
\end{align*}
以比較次數精確地算：長度 $m$ 的一段要比較 $m - 1$ 次，最壞情況共
$(n-1) + (n-2) + \cdots + 1 = \dfrac{n(n-1)}{2}$ 次，也是 $\Theta(n^2)$。

\textbf{為什麼不會比 $O(n^2)$ 更差。} 任何切法都滿足 $T(n) \le \max_{0 \le q \le n-1}\{T(q) + T(n-1-q)\} + cn$。
用代換法證明 $T(n) \le dn^2 + c'$（$d = c + c'$）：$n = 0, 1$ 時成立。 假設比 $n$ 小時都成立，
$q^2 + (n-1-q)^2$ 是 $q$ 的凸函數，在端點 $q = 0$ 或 $n - 1$ 時最大，等於 $(n-1)^2$，所以
\[
T(n) \le d(n-1)^2 + 2c' + cn = dn^2 + c' - \bigl(d(2n - 1) - cn - c'\bigr) \le dn^2 + c',
\]
最後一步是因為 $n \ge 2$ 時 $d(2n-1) \ge (c + c')n \ge cn + c'$。 因此最壞情況恰好是 $\Theta(n^2)$，而上面那種
「每次切成 $0$ 和 $m - 1$」的情況達到它。
\end{pastsoln}
