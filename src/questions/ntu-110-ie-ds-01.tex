\begin{pastexam}[label={px:ntu-110-ie-ds-01}]{臺大工工所 110 學年度 第 1 題}
（單選；每題 3 分，答錯不倒扣）

Consider the following five recursive functions:
\begin{enumerate}[label=(\Alph*)]
\item $\mathrm{T(n)}=64\mathrm{T}\left(\frac{n}{16}\right)+n(\log n)^4+n\sqrt{n}(\log n)^4$
\item $\mathrm{T(n)}=27\mathrm{T}\left(\frac{n}{8}\right)+65n\log(\log n)+3\sqrt{n}(\log n)^3+\log(n!)$
\item $\mathrm{T(n)}=11\mathrm{T}\left(\frac{n}{5}\right)+2\log^* n$
\item $\mathrm{T(n)}=\mathrm{T}(n-1)+\sqrt{n}(\log n)^2$
\item $\mathrm{T(n)}=T(\sqrt[3]{n})+1$
\end{enumerate}
Which recursion yields the highest asymptotic complexity for T(n)?
\end{pastexam}

\begin{pastsoln}
答案是 (B)。

逐一求出五個遞迴式的階（前三個用資結書第~2.4~節的主定理，後兩個用第~2.5~節的展開和換變數）：
\begin{itemize}
\item (A) $a = 64$、$b = 16$，$n^{\log_{16} 64} = n^{3/2}$（$16^{3/2} = 64$）。 $f(n) = n(\log n)^4 + n^{3/2}(\log n)^4
= \Theta(n^{3/2}\log^4 n)$，正好是 $n^{\log_b a}$ 乘上 $\log^4 n$，用資結書定理~2.5（$k = 4$）：
$T(n) = \Theta(n^{3/2}\log^5 n)$。
\item (B) $a = 27$、$b = 8$，$n^{\log_8 27} = n^{\log_2 3} \approx n^{1.585}$（$\log_8 27 = \frac{3\log 3}{3\log 2}$）。
$f(n)$ 裡 $\log(n!) = \Theta(n \log n)$（資結書第~1.6~節），其他兩項更小，所以 $f(n) = \Theta(n \log n)
= O(n^{1.585 - \varepsilon})$，取 $\varepsilon = 0.5$ 即可。 主定理情況 1：$T(n) = \Theta(n^{\log_2 3})$。
\item (C) $a = 11$、$b = 5$，$n^{\log_5 11} \approx n^{1.490}$；$f(n) = 2\log^* n$ 遠小於任何 $n^{\varepsilon}$，情況 1：
$T(n) = \Theta(n^{\log_5 11})$。
\item (D) 展開：$T(n) = T(1) + \sum_{i=2}^{n} \sqrt{i}\,(\log i)^2$。 上界 $\le n \cdot \sqrt n \log^2 n$；下界取後半段
$i \ge n/2$ 的 $n/2$ 項，每項 $\ge \sqrt{n/2}\,(\log (n/2))^2$。 所以 $T(n) = \Theta(n^{3/2}\log^2 n)$。
\item (E) 令 $n = 2^m$、$S(m) = T(2^m)$，得 $S(m) = S(m/3) + 1$，$S(m) = \Theta(\log m)$，所以
$T(n) = \Theta(\log\log n)$。
\end{itemize}

比較：(B) 的指數 $\log_2 3 \approx 1.585$ 最大。 (A)、(D) 的 $n^{1.5}$ 乘上對數的次方，任何
$\log^k n$ 都是 $o(n^{0.085})$，所以 $n^{1.5}\log^5 n = o(n^{1.585})$；(C) 的 $n^{1.490}$ 更小；(E) 只有
$\log\log n$。 由大到小是 (B) $>$ (A) $>$ (D) $>$ (C) $>$ (E)，最大的是 (B)。

容易選錯 (A)：它的 $f(n)$ 看起來最大（$n^{1.5}\log^4 n$），但決定階的是 $n^{\log_b a}$ 和 $f(n)$ 中較大的
那一個；(B) 雖然 $f(n)$ 只有 $n \log n$，遞迴部分 $n^{\log_2 3}$ 已經比 (A) 整個大。
\end{pastsoln}
