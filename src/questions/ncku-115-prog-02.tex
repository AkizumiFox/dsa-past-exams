\begin{pastexam}[label={px:ncku-115-prog-02}]{成大資訊聯招 115 學年度 資料結構問答第 3 題}
（問答）

[3\%] A binary tree stores distinct keys. Based on the following postorder and inorder sequences, please
list the keys of nodes at level 3 of the tree from left to right. Note that the root is at level 1.
\begin{itemize}
\item Postorder sequence: A B C K D I G J H F E
\item Inorder sequence: A C B D K E I G F H J
\end{itemize}
\fbox{Answer format: key1, key2, \dots}
\end{pastexam}

\begin{pastsoln}
答案：\texttt{C, K, G, H}。

用資結書第~7.4~節的方法：後序的\textbf{最後一個}是根；在中序裡找到根，左邊是左子樹、右邊是右子樹；
兩棵子樹的節點數知道了，就能把後序切成「左子樹的後序、右子樹的後序、根」。 一直遞迴下去。
\begin{enumerate}
\item 整棵樹：後序最後是 $E$，根是 $E$。 中序 $\underline{A\,C\,B\,D\,K}\;E\;\underline{I\,G\,F\,H\,J}$，
左子樹 $5$ 個、右子樹 $5$ 個。 後序切成 $A\,B\,C\,K\,D \mid I\,G\,J\,H\,F \mid E$。
\item 左子樹：後序 $A\,B\,C\,K\,D$，根 $D$。 中序 $A\,C\,B\;D\;K$：左邊 $\{A, C, B\}$、右邊 $\{K\}$。
後序切成 $A\,B\,C \mid K \mid D$。
\begin{itemize}
\item $\{A, C, B\}$：後序 $A\,B\,C$，根 $C$；中序 $A\;C\;B$，$A$ 是左子節點、$B$ 是右子節點。
\item $\{K\}$：單一節點。
\end{itemize}
\item 右子樹：後序 $I\,G\,J\,H\,F$，根 $F$。 中序 $I\,G\;F\;H\,J$：左邊 $\{I, G\}$、右邊 $\{H, J\}$。
後序切成 $I\,G \mid J\,H \mid F$。
\begin{itemize}
\item $\{I, G\}$：後序 $I\,G$，根 $G$；中序 $I\;G$，$I$ 是 $G$ 的左子節點。
\item $\{H, J\}$：後序 $J\,H$，根 $H$；中序 $H\;J$，$J$ 是 $H$ 的右子節點。
\end{itemize}
\end{enumerate}

    child {node[fill=coreFill] {K}}}

\end{tikzpicture}

檢查：這棵樹的後序是 $A\,B\,C\,K\,D\,I\,G\,J\,H\,F\,E$、中序是 $A\,C\,B\,D\,K\,E\,I\,G\,F\,H\,J$，和題目
相同。 根在第 $1$ 層，第 $3$ 層（藍底）由左到右是 $C, K, G, H$。
\end{pastsoln}
