\begin{pastexam}[label={px:ncku-113-ee-09}]{成大電機所 113 學年度 是非題第 10 題}
（是非；每題 3 分，答「錯」要指出原因，答錯倒扣 1 分）

It will waste $n$(k-1) fields if we use a list representation to represent each node in a k-ary
tree (i.e., a tree of degree k) with $n$ nodes, where each node uses a list with a fixed size k to
record its children.
\end{pastexam}

\begin{pastsoln}
這份考卷和成大電通所 113 學年度的「資料結構」是同一份（電機系、電通所、智慧資安學程共用），完整詳解見歷屆試題~\ref{px:ncku-113-cce-09}。

錯。 浪費的欄位數是 $nk - (n - 1) = n(k - 1) + 1$，不是 $n(k - 1)$。
\end{pastsoln}
