\begin{pastexam}[label={px:ust-114-ee-ds-02}]{臺聯大電機類 114 學年度 第 2 題}
（單選；2 分，答錯不倒扣）

Which of the following data structure that stores data in a first-in, last-out order?

(A)~Stack \qquad (B)~Queue \qquad (C)~Tree \qquad (D)~List
\end{pastexam}

\begin{pastsoln}
答案是 (A)。

先進後出（first-in, last-out），也就是後進先出（LIFO），是堆疊的定義（資結書第~6.1~節）：
只在頂端放入和取出，最先放進去的壓在最底下，最後才拿得出來。
\begin{itemize}
\item (A) Stack：正確。
\item (B) Queue：佇列是先進先出（FIFO），最先放進去的最先出來。 錯。
\item (C) Tree：樹是階層結構，本身沒有規定存取順序。 錯。
\item (D) List：串列可以在任何位置插入、刪除，不限定順序；只在一端操作時才是堆疊。 錯。
\end{itemize}
\end{pastsoln}
