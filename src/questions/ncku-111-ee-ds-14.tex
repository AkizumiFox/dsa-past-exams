\begin{pastexam}[label={px:ncku-111-ee-ds-14}]{成大電機所 111 學年度 單選題第 14 題}
（單選；每題 4 分）

Elements of an array are stored \underline{\hspace{3em}} in memory

A.~periodical \qquad B.~sequentially \qquad C.~in Parallel \qquad D.~None of the above
\end{pastexam}

\begin{pastsoln}
答案是 B。

陣列的元素在記憶體裡一個接一個連續存放（sequentially），第 $i$ 個元素的位址是「起點 $+ i \times$ 元素大小」，所以能在 $O(1)$
時間用索引取值（資結書第~4.1~節）。
\begin{itemize}
\item A.~periodical（週期性的）、C.~in parallel（平行的）：都不是描述存放方式的用語。 錯。
\item B.~sequentially：對。
\item D.~B 就是。 錯。
\end{itemize}
\end{pastsoln}
