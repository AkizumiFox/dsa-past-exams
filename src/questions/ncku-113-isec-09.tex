\begin{pastexam}[label={px:ncku-113-isec-09}]{成大智慧資安學程 113 學年度 是非題第 10 題}
（是非；每題 3 分，答「錯」要指出原因，答錯倒扣 1 分）

It will waste $n$(k-1) fields if we use a list representation to represent each node in a k-ary
tree (i.e., a tree of degree k) with $n$ nodes, where each node uses a list with a fixed size k to
record its children.
\end{pastexam}

\begin{pastsoln}
本卷和成大電通所 113 學年度用同一份試題，這一題和歷屆試題~\ref{px:ncku-113-cce-09} 完全相同，完整的詳解見該題。

答案：錯。 空欄位是 $nk - (n - 1) = n(k - 1) + 1$ 個。
\end{pastsoln}
