\begin{pastexam}[label={px:ntu-110-comm-dsa-35}]{臺大電信所 110 學年度（B）第 35 題}
（單選；每題 2 分，答錯不倒扣）

Please choose the best possible answer in each of the following questions. In questions that ask for time complexities, please choose the tightest bound.

For problems 32 to 35, please consider a graph with $|V|$ vertices and $|E|$ edges, to which the Dijkstra algorithm is applied to find the shortest path. Assume $|E|$ is both $O(|V|^2)$ and $\Omega(|V|)$.

If Dijkstra algorithm is implemented with doubly-linked list as priority queue, then the complexity is

A.~$O(|V|^2+|E|\log|V|)$ \qquad B.~$O(|V|^2)$ \qquad C.~$O(|E|\log|V|)$\\
D.~$O(|E|+|V|\log|V|)$ \qquad E.~$O(|E|)$
\end{pastexam}

\begin{pastsoln}
Dijkstra 演算法對優先佇列做 $|V|$ 次插入（或一開始建好）、$|V|$ 次 \proc{Extract-Min}、至多 $|E|$ 次
\proc{Decrease-Key}（每條邊鬆弛一次），總時間
\[
|V| \cdot T_{\text{extract}} + |E| \cdot T_{\text{decrease}} + (\text{建佇列})
\]
（資結書第~25.2~節）。

題目沒說串列有沒有排序。 採用一般的做法：\textbf{未排序}的雙向鏈結串列，每個頂點一個節點，另用陣列
記住每個頂點的節點位置。
\begin{itemize}
\item \proc{Extract-Min}：要掃整個串列找最小，$O(|V|)$；找到後從雙向串列刪除 $O(1)$。
\item \proc{Decrease-Key}：直接改節點裡的 $d$ 值，串列沒有順序要維持，$O(1)$。
\end{itemize}
總時間 $|V| \cdot O(|V|) + |E| \cdot O(1) = O(|V|^2 + |E|)$。 題目假設 $|E| = O(|V|^2)$，化簡成
$O(|V|^2)$，選 B。 這和用陣列實作的 Dijkstra 相同，在稠密圖上反而比二元堆積好。

若改用\textbf{排好序}的串列，\proc{Extract-Min} 變成 $O(1)$，但每次 \proc{Decrease-Key} 要把節點往前移到
正確位置，最壞 $O(|V|)$，總時間 $O(|V||E|)$，不在選項裡；所以題意應是未排序的串列。
A 雖是上界但不是最緊的。
\end{pastsoln}
