\begin{pastexam}[label={px:nccu-115-dsa-10}]{政大資科所 115 學年度 第 10 題}
（單選）

(5\%) The Master Theorem case that applies to the recurrence $T(n)=2T\left(\frac{n}{2}\right)+n\log n$
results in which time complexity?

(A)~$O(n)$ \qquad (B)~$O(n\log n)$ \qquad (C)~$O(n\log^2 n)$ \qquad (D)~$O(n^2)$
\end{pastexam}

\begin{pastsoln}
答案是 (C)。

$a = 2$、$b = 2$，$n^{\log_b a} = n$，$f(n) = n\log n$。 基本的主定理（資結書定理~2.4）三種情況都
不適用：$f(n)$ 比 $n$ 大，所以不是情況 1、2；但 $f(n)/n = \log n$ 比任何 $n^{\varepsilon}$ 都小，
$f(n)$ 不是「多項式地」比 $n$ 大，情況 3 也不成立。 這個遞迴式落在情況 2 和 3 之間的縫隙裡。

要用的是延伸的情況 2（資結書定理~2.5）：若 $f(n) = \Theta(n^{\log_b a}\lg^k n)$，則
$T(n) = \Theta(n^{\log_b a}\lg^{k+1} n)$。 這裡 $k = 1$，得到 $T(n) = \Theta(n\lg^2 n)$。

也可以用遞迴樹直接算（$n = 2^m$）。 第 $j$ 層有 $2^j$ 個子問題，每個大小 $n/2^j$，這一層的成本是
\[
2^j \cdot \frac{n}{2^j}\lg\frac{n}{2^j} = n(\lg n - j),
\]
$j = 0, 1, \ldots, \lg n - 1$ 加起來是
\[
n\sum_{j=0}^{\lg n - 1}(\lg n - j) = n\cdot\frac{\lg n(\lg n + 1)}{2} = \Theta(n\lg^2 n),
\]
葉子那層再加 $\Theta(n)$，總共 $\Theta(n\lg^2 n)$。 （對數的底只差常數倍，$\log$ 和 $\lg$ 都一樣。）

逐項檢查：
\begin{itemize}
\item (A) $O(n)$、(B) $O(n\log n)$：光是最上面兩層就有 $n\lg n + n(\lg n - 1)$，而總和是
$\Theta(n\lg^2 n)$，比 $n\log n$ 大一個 $\log n$ 倍，這兩個都不是上界。 錯。
\item (C) $O(n\log^2 n)$：正確而且是緊的界。
\item (D) $O(n^2)$：作為上界是成立的，但太鬆，不是主定理得到的結果。 不選。
\end{itemize}
\end{pastsoln}
