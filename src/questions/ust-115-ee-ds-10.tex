\begin{pastexam}[label={px:ust-115-ee-ds-10}]{臺聯大電機類 115 學年度 第 10 題}
（單選；2 分）

Inserting a node named ``new'' after a node named ``p'' in a doubly linked list (assuming p is not
the last node), which of the following four lines of code is in the correct order?

\begin{tabular}{l}
1. \texttt{new->next = p->next;}\\
2. \texttt{p->next->prev = new;}\\
3. \texttt{p->next = new;}\\
4. \texttt{new->prev = p;}
\end{tabular}

(A)~1 -> 3 -> 2 -> 4 \qquad (B)~3 -> 4 -> 1 -> 2 \qquad (C)~1 -> 2 -> 4 -> 3 \qquad (D)~3 -> 1 -> 4 -> 2
\end{pastexam}

\begin{pastsoln}
答案是 (C)。

設插入前 $p$ 的下一個節點是 $q$（$p$ 不是最後一個，所以 $q$ 存在）。 插入後要變成
$p \leftrightarrow \mathit{new} \leftrightarrow q$，四個指標要改：$\mathit{new}$ 的
$\mathit{next}$、$\mathit{prev}$，$q$ 的 $\mathit{prev}$，$p$ 的 $\mathit{next}$。 關鍵是第 1、2
行都要透過 \texttt{p->next} 找到 $q$，所以第 3 行（改掉 \texttt{p->next}）必須排在 1、2 之後
（資結書虛擬碼~5.6 也是最後才改 $p.\mathit{next}$）。

逐項追蹤：
\begin{itemize}
\item (A) 1、3、2、4：做完 1、3 後 \texttt{p->next} 已經是 $\mathit{new}$，第 2 行變成
\texttt{new->prev = new}；$q.\mathit{prev}$ 仍指向 $p$，接著第 4 行把 \texttt{new->prev} 改回
$p$。 結果 $q$ 往回走會跳過 $\mathit{new}$。 錯。
\item (B) 3、4、1、2：先做 3，$q$ 就找不到了。 第 1 行變成 \texttt{new->next = new}，第 2 行變成
\texttt{new->prev = new}，串列從 $\mathit{new}$ 之後斷掉。 錯。
\item (C) 1、2、4、3：\texttt{new->next} $= q$，$q.\mathit{prev} = \mathit{new}$，
\texttt{new->prev} $= p$，最後 \texttt{p->next} $= \mathit{new}$。 四個指標都對。 對。
\item (D) 3、1、4、2：同 (B)，一開始就改掉 \texttt{p->next}，$q$ 遺失。 錯。
\end{itemize}
\end{pastsoln}
