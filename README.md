# 資料結構與演算法研究所考古題詳解

作者：林子祐

台灣各校研究所入學考試「資料結構與演算法」的原題，每一題附完整詳解。 是[《資料結構與演算法：C 語言、虛擬碼與研究所考試》](https://github.com/AkizumiFox/dsa-c-book)（以下簡稱資結書）的習題本：**依主題排**，章號、章名都和資結書一樣，讀完資結書的一章就可以做這本書的同一章。 想整份考卷計時練習的話，每一冊的附錄「依考卷查題」列出每份考卷的每一題在第幾頁。

## 分冊

| 冊 | 範圍 | 狀態 |
|---|---|---|
| 一 | 資工所（含資訊聯招、資科所、合卷與計概裡的資料結構題）106–110 學年度 | 初稿完成（47 份、320 題） |
| 二 | 資工所 111–115 學年度 | 初稿完成（58 份、614 題） |
| 三 | 他系「資料結構」（電機、電信、資管等）106–115 學年度 | 初稿完成（66 份、851 題） |
| 四 | 國家考試三等「資料結構」：高考三級、地方特考三等、關務特考三等，96 年起 | 初稿完成（58 份、279 題） |

## 題目和詳解

- 題目照原卷：語言、記號、配分、選項都不改，原卷的圖用 TikZ 重畫。 原卷有錯字或條件不足時，詳解第一段會說明採用的解讀。
- 詳解是作者寫的，不是各校公布的答案：選擇題逐個選項說明，追蹤題寫出每一步，證明題寫完整證明，設計題附虛擬碼、正確性理由和複雜度。 數值答案都用程式驗算過。
- 合卷只收資料結構與演算法的題目。

## 編譯

需要 XeLaTeX（TeX Live）、`latexmk`、Python 3 與 PyYAML。

```sh
make vol1   # 產生 output/vol1.pdf（vol2–vol4 同理）
```

`src/questions/` 每題一個檔（題目＋詳解），`src/meta/` 每份考卷一個 YAML（題號、歸到哪一章），`scripts/assemble.py` 依主題組成一冊。
